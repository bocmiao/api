# 实时票房恢复与数据边界（v0.13.1）

PR #1原始提交：`6f64019dd44dcc6371cb1f6f79366b927c36f1b3`，基线：`2a3ff580f883b00ec3097ef953bc86b36030ec28`。

上游改为猫眼专业版网页端 `https://piaofang.maoyan.com/dashboard-ajax/movie`；仍是平台网页源，不是本站生成的票房数据，不承诺稳定公开API。影片box/splitBox从分换算成万元；全国综合与分账大盘各自保留万/亿单位，累计票房保留带单位文本。接口路径、limit和已有响应字段保持兼容，无数据库迁移或新增依赖。

本轮修复了全缺元数据空壳被缓存为成功的问题。合法零票房空榜须有统计日期（或可换算的更新时间）及至少一个大盘数值，0不会当成缺失；无有效统计信息则502，由已有缓存层保留旧数据。无效日期、时间戳、单位返回502；布尔、空白、对象不会变成金额0，正常数值金额仍按原含义换算。

默认仍缓存2分钟；上游错误在原缓存策略允许的时段内返回旧数据并保留stale标记。HTTP403、HTML或无数据结构不能冒充成功。旧缓存跨午夜仍可能短暂保留上一统计日，应以date/serverTime和stale判断，不把缓存称为当天新数据。

验证覆盖普通/亿单位、缺失值、零值空榜、坏日期和时间戳、空壳刷新保留旧缓存、limit共享缓存、暂停模块的目录/巡检/预热/503，以及旧版读取中文更新说明。

实测边界：作者提供过无签名响应和fixture；本环境2026-10-18的无凭据公开读取被环境代理在CONNECT阶段拒绝（403，目标HTTP状态000），没有取得猫眼实时响应。本次不将模拟数据或作者说明当作独立在线验证，未绕过签名、验证码或访问限制。实际线上可用性仍须在允许访问该端点的环境低频核验。
